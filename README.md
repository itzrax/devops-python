# DevOps Python Portfolio

A collection of Python scripts built for real DevOps, Cloud, and Security engineering tasks.

## Projects

### Day 01 — Server Health Checker
Monitors server status and CPU usage. Flags critical servers and generates a summary report.

### Day 02 — File-Based Health Reports
Reads server data from a CSV file and writes timestamped health reports to disk.

### Day 03 — JSON & YAML Reports
Upgrades the health checker to use JSON and YAML formats used in real DevOps tooling.

### Day 04 — GitHub API Inspector
Calls the GitHub API to inspect user accounts, detect suspicious profiles, and generate reports.

### Day 05 — Secrets Management
Secures API credentials using environment variables and .env files. Never hardcodes secrets.

### Day 06 — Log Analyzer
Parses application logs, flags ERROR and WARNING events, and generates alert reports.

### Day 07 — Docker Container Monitor
Uses the Docker SDK to monitor running containers and report their status and uptime.

### Day 08 — CI/CD Pipeline
GitHub Actions workflow that automatically runs health checks and log analysis on every push.

### Day 09 — Brute Force Detector
Analyzes SSH auth logs to detect brute force attacks, flag threat IPs, and identify targeted usernames.

### Day 10 — DevOps Security Monitor (Capstone)
Combines all modules into one unified tool — server health, log threat detection, and GitHub inspection.

## Tools & Technologies
- Python 3.12
- GitHub Actions (CI/CD)
- Docker SDK
- REST APIs (GitHub API)
- JSON, YAML
- Linux, WSL
